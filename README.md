# Пъдпъдъчи яйца — обновления

Тук стоят само готовите инсталатори на програмата за проследяване на
пъдпъдъчи яйца. Няма код и няма ключове.

Инсталираната програма поглежда тук при стартиране и сама предлага
новата версия, когато има такава.

За да инсталирате ръчно, отворете **Releases** отдясно и изтеглете
файла `PadpadachiYaytsa-Setup-....exe` от най-горната версия.
